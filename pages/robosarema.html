Misi & Kompleksitas Arena SAR

Kontes Robot SAR Indonesia (KRSRI) menuntut robot otonom untuk bernavigasi menembus arena simulasi reruntuhan bencana (tangga, tanjakan miring, lorong sempit, dan puing rintangan). Robot ditugaskan menemukan korban bencana secara mandiri, membedakan tanda visual/termal, dan mengirim sinyal penyelamatan.

Sebagai Software Division Researcher, fokus utama saya adalah merancang sistem persepsi visual cerdas yang mampu bekerja dengan latensi sangat rendah (*low latency*) pada perangkat komputasi bergerak (*embedded board*) di tengah kondisi pencahayaan arena yang dinamis.

Riset & Kontribusi Teknis

🎯

Deteksi Korban Real-Time

Mengimplementasikan model object detection kustom untuk mendeteksi boneka korban dan target identifikasi secara akurat pada FPS tinggi (25-30+ FPS).

🔄

Pipeline Pengambilan Keputusan

Merancang alur konversi dari koordinat bounding box piksel kamera menjadi koordinat spasial relatif untuk dikirim via protokol serial ke mikrokontroler penggerak robot.

💡

Kalibrasi Kondisi Ekstrem

Menerapkan teknik image preprocessing dan color space filtering (HSV/LAB) untuk mengantisipasi bayangan tajam, pantulan lantai, dan variasi intensitas lampu arena.

⚡

Optimasi Edge Computing

Melakukan kuantisasi model (TensorRT/ONNX) untuk memaksimalkan efisiensi komputasi GPU embedded tanpa mengorbankan akurasi deteksi.

Teknologi & Alat Riset

🐍 Python 👁️ OpenCV ⚡ YOLOv8 / YOLOv5 🐧 Ubuntu Linux 🔌 Serial UART / USB Comm 💻 Jetson / SBC Computing
