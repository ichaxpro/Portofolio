Tentang Website Profil LAB DT

Laboratorium Desain & Teknologi (LAB DT) di Politeknik Negeri Malang membutuhkan platform digital representatif untuk mempublikasikan kegiatan riset, profil pengajar/anggota lab, inventaris perlengkapan canggih, serta portofolio karya inovasi mahasiswa.

Dalam proyek ini, saya memegang dua peran kunci: sebagai Project Manager yang memimpin jalannya tahapan rekayasa perangkat lunak, sekaligus sebagai Full-Stack Developer yang mengimplementasikan arsitektur database, sistem CRUD, dan desain antarmuka.

Peran & Fitur Unggulan

📅

Manajemen Timeline & Sprint

Menyusun timeline pengembangan, alokasi tugas tim, review mingguan, dan memastikan delivery fitur tepat waktu sesuai spesifikasi stakeholder.

🔐

CRUD Admin & Member

Mengembangkan modul pengelolaan data dinamis (berita, galeri riset, inventaris, dan akun member) dengan otentikasi role-based yang aman.

🎨

Rancangan UI Homepage Modern

Mendesain tampilan antarmuka berkesan teknologi tinggi dan bersih, menampilkan showcase riset unggulan dengan navigasi yang responsif.

🗄️

Arsitektur Database Relasional

Merancang skema database MySQL teroptimasi dengan relasi antarentitas yang efisien dan query yang terhindar dari bottleneck performa.

Teknologi yang Digunakan

🔴 Laravel ⚡ Livewire / Blade 🎨 Tailwind CSS 🐬 MySQL Database 🐙 Git & GitHub 🦖 Laragon / Local Server 📋 Project Management & Scrum
